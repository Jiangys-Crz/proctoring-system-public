# 程序设计算法协会监考系统安装使用指南

## Windows 安装与启动

### 01 下载 Windows 安装包

在[下载页面](/)选择 **Windows 版**，下载安装包。

### 02 保留浏览器下载的安装包

如果浏览器拦截下载安装包，请点击右侧的 **三个点**，再选择 **仍要保留**。

### 03 选择安装目录

打开安装包，选择合适的目录位置，点击 **安装**。

### 04 完成安装

安装完成后，取消勾选 **运行程序设计算法协会监考客户端**，再点击 **完成**。

### 05 以管理员身份启动

在桌面找到监考软件，右键点击图标，选择 **以管理员身份运行**。

## Mac 安装与授权

### 01 下载对应的 Mac 安装包

在[下载页面](/)选择与你的 Mac 芯片类型对应的安装包：**Apple 芯片版**或 **Intel 版**。

### 02 保留浏览器下载的安装包

如果浏览器拦截下载安装包，请点击右侧的 **三个点**，再选择 **仍要保留**。

### 03 将客户端放入应用程序

打开下载的 **DMG 安装包**，将监考客户端图标拖入 **Applications（应用程序）**。

### 04 允许打开客户端

如果系统提示无法验证或打开软件，先点击 **完成**。然后打开系统设置中的 **隐私与安全性**，向下滚动，找到“已阻止打开程序设计算法协会监考客户端”的提示，点击 **仍要打开**，即可启动软件。

### 05 完成权限检查

客户端打开后，点击还未获得权限的卡片，按提示完成相应权限授权。

### 06 重新添加未生效的权限

如果已经授权，但点击 **检测系统权限** 后仍显示没有权限，请按下面的顺序重新添加客户端。

**第一步：移除旧的权限记录。** 点击对应权限卡片，打开系统设置页面，选中 **程序设计算法协会监考客户端**，点击下方的 **−** 号进行移除。

**第二步：重新添加并授权。** 点击 **＋** 号，在 **应用程序** 中找到 **程序设计算法协会监考客户端**，选中并打开，再重新赋予权限。

## 登录测试流程

### 01 领取测试账号

打开[测试页面](/test)，输入 **协会官网账号和密码**进行验证，即可领取测试账号。

没有账号？请先前往[协会官网](https://example.org)注册，再返回领取测试账号。

### 02 在监考客户端进入登录

完成监考客户端的权限验证后，点击 **登录**。

### 03 使用手机扫码登录

使用手机浏览器（推荐使用 **百度浏览器**）扫描客户端二维码，再填写领取的 **测试账号信息**进行登录。
