# 客户端 1.0.11：Mac 安装与版本确认

Mac Intel、Mac Apple Silicon 与 Windows 统一使用版本号 1.0.11，包含最新的内网 NovaJudge submit / printfile、Windows 7 离线依赖准备、实时语音和 USB 防误报修复。

## Mac 更新流程

旧流程只下载并打开 DMG，没有替换已安装的应用。打开新副本时，单实例逻辑还可能直接唤回仍在运行的旧版，因此下载结束不代表正在运行的版本已更新。

新版从 DMG、下载目录等位置启动时，在获取单实例锁之前提示安装到“应用程序”。确认后使用 Electron 的系统安装流程替换并重新打开应用；如旧版仍在运行，拒绝静默切回旧版，提示先完全退出。取消授权或复制失败不会继续进入考试或宣称安装成功。

从 0.1.23 等旧版升级时：

1. 用菜单“退出”或 Command-Q 完全退出旧客户端，正在考试时先完成考试。
2. 下载与机器架构对应的 1.0.11 DMG，打开其中的新版客户端。
3. 选择“安装并重新打开”，按系统提示完成替换。
4. 从“应用程序”启动，确认显示当前版本 1.0.11；避免继续打开下载目录中的旧副本。

Windows 继续使用原安装路径完成安装向导。

## 发布验证

打包时同时核对源码版本、安装包内 `package.json` 版本，以及 Mac 的 `CFBundleVersion` 和 `CFBundleShortVersionString`；不一致即停止打包。安装包中的实际程序支持 `--proctor-version`，用于验证运行版本和架构，不启动考试、采集设备或更改安装目录。

发布前验证桌面和网页回归测试、两种 Mac DMG 的实际内容和运行版本、Windows 安装器的两种架构载荷，并核对下载文件校验和。后台在本机构建 Linux amd64 镜像后上传；切换前保留数据库、配置和旧镜像，先在隔离环境验证。
