# 登录限制与考室管理

## 登录限制

在监考后台打开某场考试，点击“登录限制”。每场正常考试默认启用 IP 登录限制。

- 考生第一次成功登录后，绑定电脑端的登录 IP；相同考试、相同考号再次登录必须使用该 IP。
- 第二机位的手机可以使用其他网络，其 IP 不会替代电脑端的绑定。
- 监考老师可以在所管理的考室中选择一名或多名考生，点击“解除一次限制”。解除后，下一次成功登录绑定新的 IP，并恢复限制。密码错误不会消耗解除机会，原客户端持续轮询也不会消耗解除机会。
- 更换设备登录成功后，原设备的会话和登录凭据失效，考试原有开始时间、截止时间继续保留。
- 考试管理员可以关闭或重新启用整场考试的 IP 限制，开关立即影响后续登录。关闭期间仍记录最近一次成功登录的电脑 IP，重新启用后使用该 IP。
- 关闭 IP 限制不会解除“同一考号不能同时登录多个有效考试会话”的规则。需要立即更换设备时，应先为该考生解除一次限制。
- 登录限制仅管理登录，不会因为考试期间网络地址变化而直接结束考试。已结束考试不能通过解除 IP 绑定重新登录。

## 考室管理

“添加考室”始终创建一个新考室。页面自动刷新不会把新增表单变成已有考室的编辑表单。

同一场考试的考室名称必须唯一。新增同名考室或修改为已有名称时会明确提示，已有考室、考生和监考老师分配保持原样。

一位监考老师可以同时分配给多个考室。修改某个考室的监考老师，不会移除其在其他考室的分配。

## 后台直播播放

视频监考与 API Key 直播入口均使用 WebRTC。信令接口持续交换 ICE 候选地址，网络恢复后自动重连；播放执行原有监考权限校验。

内网媒体容器必须能解析 `proctorrtc.example.test` 到内网服务器自身地址。内网部署可参考 `deployment/docker-compose.host.example.yml` 配置该主机自己的映射。公网服务器使用其自己的域名解析和端口配置，不应复制内网映射。
