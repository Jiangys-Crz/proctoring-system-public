# 客户端 1.0.4 更新说明

本版本继续使用统一安装包：包含 Windows 32 位和 64 位组件，优先连接内网的四个服务域名，内网不可达时回退原公网服务。内网和公网使用各自的后台配置、账号和安装包发布记录。

## 控屏图片一直加载

修复图片已下载、展示窗口尚在加载时丢失展示事件的问题。展示页面订阅完成后主动请求最新图片，窗口加载结束后再次补发，页面异常重载后也会重新交付缓存图片。保持原有全屏、输入拦截、多显示器和监考锁定规则。

## Windows 7 稳定性与权限检测

- 权限检测并行读取系统、网络、采集和设备信息，复用已成功验证的硬件型号信息，减少重复扫描；失败的检测仍可重试。
- Windows 7 使用兼容的 DNS 查询方式，保留原生进程、虚拟机、外设和活动窗口检测。
- Windows 7 屏幕和前置摄像头采集设为 15 帧/秒，录像设为 10 帧/秒，并优先使用 VP8 录像编码，降低旧电脑的处理负担。保留屏幕原有分辨率上限和文字清晰度。
- 页面进程意外退出后，客户端从主进程内存恢复原考试会话，先向原服务器验证，再恢复监考、推流和考试网页。保留原开始时间、结束时间、第二机位关联和锁定状态，不新建考试登录。恢复凭据不写入浏览器存储或磁盘文件。
- 两分钟内反复崩溃达到恢复次数上限时保留日志并提示联系监考老师，避免无限重载。日志包含退出原因与客户端版本；旧的“重新安装”提示不再作为运行中崩溃的通用原因。

这些修改已通过客户端测试及 Electron 22 引擎的实际页面崩溃恢复、控屏图片解码检查。故障 Windows 7 电脑的退出日志尚未取得，因此不能确认所有旧系统、驱动和内存故障均已消除。出现再次退出时，应保留用户数据目录下的 `logs` 与 `Crashpad` 目录用于进一步排查。

## 监考画面加载及放大

后台视频监考和直播 API Key 播放共同使用 WebRTC。初始协商立即发送，后续持续补齐网络候选地址，不等待整批地址收集完成。

点击放大或退出放大时直接改变原画面的显示尺寸，沿用原视频元素和观看连接。后台定时刷新考生状态也不会重新连接同一会话、同一机位。按 Esc 可以退出放大。

内网浏览器协商使用 Chrome 支持的 `18189` 端口，原 `443` 推流入口继续保留。等待首帧期间不会提前按“播放卡顿”重建连接；连接关闭时先清除旧视频，防止浏览器占位帧被误标成“实时”。

直播地址、密钥启停和接入方式见 [直播流使用说明](直播流使用说明.md)。登录限制、解除一次限制及考室规则见 [登录限制与考室管理说明](登录限制与考室管理说明.md)。

## 安装与考试

从对应后台下载 1.0.4 完整安装包，并在考试前完成安装及权限、画面检查。正在考试的客户端不应为了安装更新而中途退出。
